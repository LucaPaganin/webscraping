eBay and Vinted Scraping
===================

This module provides tools for scraping product listings from eBay and Vinted.

Streamlit Scraper
---------------

.. automodule:: ebay-vinted.streamlit_scraper
   :members:
   :undoc-members:
   :show-inheritance:

The streamlit scraper provides a user-friendly interface for scraping and analyzing product listings from eBay and Vinted.

Key Features
^^^^^^^^^^^

* Interactive web interface using Streamlit
* Scraping from both eBay and Vinted platforms
* Session state data storage for immediate analysis
* CSV file export and upload capabilities
* Advanced filtering and analysis tools

Helpers Module
------------

.. automodule:: ebay-vinted.helpers
   :members:
   :undoc-members:
   :show-inheritance:

The helpers module provides utility functions for scraping, data processing, and analysis.

Key Components
^^^^^^^^^^^

* Session state management for storing scraped data
* Data transformation and cleaning functions
* CSV file handling functions
* Filtering and sorting utilities
